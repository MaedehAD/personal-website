# Maedeh Agharazzi Academic Website

A responsive, minimal academic portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

### GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Choose the main branch and root folder.

### Netlify or Vercel
Drag the folder into Netlify, or import the repository into Vercel.

## Customize

- Main content: `index.html`
- Colors and design: `styles.css`
- Navigation and animations: `script.js`
- CV file: `assets/Maedeh-Agharazzi-CV.pdf`
