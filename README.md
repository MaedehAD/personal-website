# Maedeh Agharazi Academic Website
Upload all files and the entire assets folder to the root of the GitHub repository. Then enable Settings → Pages → Deploy from a branch → main → /(root).

Live URL: https://maedehad.github.io/personal-website/

To add your headshot, upload `headshot.jpg` into `assets`, then replace `assets/headshot-placeholder.svg` with `assets/headshot.jpg` in index.html.
