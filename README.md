# Maedeh Agharazi Academic Website v2

Upload all files and the `assets` folder to the root of the `MaedehAD/personal-website` repository.

GitHub Pages settings:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Live URL:
https://maedehad.github.io/personal-website/

To add your headshot:
1. Rename it `headshot.jpg`.
2. Upload it to `assets/`.
3. In `index.html`, replace `assets/headshot-placeholder.svg` with `assets/headshot.jpg`.
